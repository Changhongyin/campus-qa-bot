# 量大智答 · 里程碑开发计划（dev-plan）

> 版本：v2.0 ｜ 原则：先主干后防御、数据先于界面、验收前置

## M1 项目骨架与依赖治理
- 产出：目录结构、package.json、tsconfig、health 接口、运行验证。
- 验收：npm install 成功；/api/health 返回 200 并透出知识库/密钥状态。

## M2 DeepSeek 直通
- 产出：DeepSeek 封装（OpenAI 兼容协议、60s 超时、错误带状态码）、chat 路由入参校验 + 历史清洗（限 10 条）。
- 验收：校况问题回答正确；多轮「它有哪些校区」代词指代正确。

## M3 拒答闸门（防御）
- 产出：别名快判 + 大模型意图分类兜底，统一拒答话术 + 问候识别。
- 验收：笑话/写代码/天气被拒；「食堂在哪个校区」「考研分数」正确放行。

## M4 知识库引擎（语义检索）
- 产出：切块≤600 字、向量化（语义嵌入）+ TF-IDF 降级、Top-3 注入、指纹热更新、来源溯源。
- 验收：私有资料精准命中并溯源；新增即时生效、删除即时失效、免重启。

## M5 前端界面
- 产出：聊天界面、三态来源徽标、加载动画、示例问题、Enter 发送、免责声明。
- 验收：tsc --noEmit 零错误、vite build 成功。

## M6 端到端联调
- 产出：测试脚本参数化 base_url，经代理重跑全量测试，逐条核对 PRD 验收标准。
- 验收：冒烟 10/10、边缘 17/17。

## M7 交付
- 产出：README（从零启动）、三份文档同步、总体验收（投毒/泄露/畸形文件/20 路并发）。
- 验收：final_acceptance 22/22、密钥 grep 零泄露、任何人可复现。
